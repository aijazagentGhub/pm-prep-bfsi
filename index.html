Q1: How do you use "The Mom Test" for BFSI features?
Instead of asking for opinions on a new feature, focus on unmet needs in past behaviors. This prevents users from being "polite" about bad ideas.
Example: Instead of "Would you use an AI budgeter?", ask "When was the last time you exceeded your monthly spend? How did you try to track it then?"

Q2: Vision vs. Mission in a PM Context?
Vision is the "North Star"—the world you want to create (5+ years). Mission is the "Vehicle"—what you are doing today to drive toward that vision.
Example (Wise): Vision: Money without borders. Mission: Building the world's most transparent, lowest-fee payment network.

Q3: How do you prioritize features with high tech-debt?
Use the RICE framework but categorize tech-debt as a "Reliability" pillar. If debt causes downtime, it impacts the "Confidence" score of all other features.
Example: Delaying a new UI to fix API latency because slow response times in banking lead to immediate trust loss.
Deep Dive Link
Q4: Explain AI "Hallucinations" in Financial Products.
In BFSI, accuracy is non-negotiable. Hallucination occurs when an LLM provides false financial data. PMs must use RAG (Retrieval-Augmented Generation) to anchor AI in real bank records.
Example: An AI bot shouldn't "guess" a credit card's APR; it must pull specifically from the customer's legal contract.
